## Quality Signals

### Generic responses

The regression suite checks that context-specific objective, request, project, knowledge, and evidence blocks survive assembly. This is a deterministic proxy for context loss; it is not a measurement of human-rated response helpfulness.

### Unsupported claims

When no evidence is supplied, the confidence layer returns `Unknown` and an open question instead of fabricating support.

### Context drift

Long histories are bounded by the existing 20-message model-history limit while the current request, objective state, and derived context remain explicit. The regression suite verifies that the newest history message is retained.

### Contradictions

The evidence layer's conservative conflict heuristic is exercised with opposing evidence. A conflict produces a `Low` confidence assessment and an explicit review question.

## Performance

The 500-message context assembly test uses a conservative local regression ceiling of 250 ms. This is a regression guard against accidental algorithmic slowdown, not a hardware-independent latency guarantee.

## Limitations

This milestone does not claim to measure subjective answer quality or actual model hallucination rates without a live model evaluation corpus. Those require a controlled evaluation dataset and model-backed scoring. 4.3.1-G therefore records deterministic regression evidence and avoids inventing quality metrics.
