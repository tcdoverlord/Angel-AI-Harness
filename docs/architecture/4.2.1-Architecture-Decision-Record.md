# ADR-001: Remove Work Mode

## Status
Accepted

## Decision
Angel 4.2.1 removes Work Mode as a dedicated user experience.

## Rationale

Users should not be required to decide whether they are chatting or working. Work is represented through project context rather than a separate operating mode.

## Consequences

Positive:
- Simpler UI
- Simpler state model
- Reduced QA surface
- Better alignment with One Assistant · One Workspace · One Context

Negative:
- Dedicated work progress visualization deferred

## Future Direction

Introduce Task and Activity capabilities only when justified by actual usage data.
