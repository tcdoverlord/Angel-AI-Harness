# Angel 4.3.1-A — Conversation Pipeline Audit

## Current Request Flow

```text
HTTP /api/chat
  ↓
Validate message + conversation
  ↓
ConversationStore / SQLite conversation
  ↓
Knowledge search
  ↓
Append user message
  ↓
Load up to 20 recent messages
  ↓
Build system prompt
  ↓
Add conversation history
  ↓
Send to Ollama (when available)
  ↓
Stream response
  ↓
Persist assistant response
```

## System Prompt

The current system prompt includes Angel's conversational behavior, the selected cooperative AI lane, application date/time context, capability report, local history-path information, and the retrieved knowledge context when available.

## Project Context

The server resolves the conversation's persisted `project_id`, but the current ordinary chat system prompt does not inject the resolved project context into the model prompt. Project context is used by the existing runtime observation/RAG record path.

## Knowledge

The current chat path searches Angel knowledge for the user message and injects the resulting knowledge context into the system prompt.

## Evidence

Existing RAG/evidence infrastructure records retrieved knowledge observations after/around a chat request. Evidence is not currently a general-purpose input block in the ordinary Ollama prompt.

## Tool Results

Deterministic application routes can return verified results directly to the user. Those results are not currently fed back into a subsequent Ollama context block by the ordinary `/api/chat` flow.

## Memory

The current ordinary chat request does not inject approved memory records into the model prompt.

## Ollama Request

Angel sends a JSON request to the local Ollama `/api/chat` endpoint containing the selected model, the assembled `messages` array, and `stream: true`.

## Conversation Storage

SQLite is the authoritative runtime storage layer. The primary tables are `conversations` and `messages`. The existing database layer also maintains project relationships and supports legacy `chat_history.json` migration.

`chat_history.json` remains as a compatibility/export copy.

## Current History Limit

The current model prompt includes up to **20 recent conversation messages**. 4.3.1-A instruments this behavior but does not change it.

## Diagnostic Token Measurement

4.3.1-A records a transparent **estimated** token count using approximately four characters per token. This is instrumentation, not a model tokenizer measurement. A future context-engine phase can replace this estimate with model-specific accounting.
